# Melon Miles

A pixel-art trip picker. Choose where you are flying from, the month, how many days, a budget in pounds, and the kind of place you want. Melon Miles suggests trips that fit that budget, with a packing list and a shareable card.

It does not search live flights, hotels, or weather, and it does not book anything. Costs are rough estimates in GBP. Nothing is saved when you close the tab.

## Try it

Open `index.html` in a browser.

## What you can do

- **Find Destinations** shows up to three trips inside your budget. If a full-length trip does not fit, it suggests a shorter stay that does.
- **Surprise Me** spins the reels, picks another trip that fits the budget, and updates the suggestions on the page.
- **Share** downloads a pixel card as a PNG.

The guide includes 30 destinations and 20 airports. Temperature is Hot, Mild, or Cold. Kind of place is Sunny, Green, or Cultural.

## How it is built

One HTML file, with the CSS and JavaScript inside it. The only outside request is the Press Start 2P font.
